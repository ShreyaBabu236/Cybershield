# Demo script

This demo uses only synthetic fixtures and generated data. It shows the parser, evaluation code, and the import pipeline.

## 1. Build and test

From the repository root:

```powershell
mvn package
mvn test
```

Expected: Maven builds the Java 21 project and the JUnit suite completes successfully.

## 2. Launch the desktop shell

```powershell
mvn javafx:run
```

Show the main window. Import `data/sample/auth_sample.log` with the Auth log format (22 events, 4 alerts, 3 incidents, 2 malformed lines reported), then open the Alerts, Incidents and Dashboard tabs. The Dashboard shows the stored event count, incidents, severity chart, selected-incident timeline and root causes. Importing the same file again is skipped, and Clear data empties the database. Nothing is seeded or fabricated: with an empty database the dashboard shows zero counts.

## 3. Parse the equipment-alarm sample

Open [`data/sample/equipment-alarms.csv`](../data/sample/equipment-alarms.csv) and [`docs/data-formats.md`](data-formats.md). Point out the synthetic comment, header, five fields, and timestamp format. The sample rows are accepted by `EquipmentAlarmCsvParser`, which is offered in the app's Format box and imports the file. [`data/sample/auth_sample.log`](../data/sample/auth_sample.log) is the synthetic authentication sample for `AuthLogParser`.

The parser and checked-in CSV sample are covered by `EquipmentAlarmCsvParserTest` and `EquipmentAlarmCsvSampleTest`. To run that focused verification:

```powershell
mvn -Dtest=EquipmentAlarmCsvParserTest,EquipmentAlarmCsvSampleTest test
```

## 4. Explain root-cause training/evaluation

The implemented API is `RootCauseEvaluation.evaluate(trainingSeed, testSeed, cascadesPerDataset, skewTolerance)`. It evaluates 0, 1, and 3 seconds of injected skew and trains a separate ranker only from each training split. The returned `EvaluationReport.toTable()` string contains measured baseline/ranker top-1 and top-3 counts and accuracy.

For a deterministic test-backed example, run:

```powershell
mvn -Dtest=RootCauseEvaluationTest,SyntheticCascadeGeneratorTest test
```

The actual sample report should be generated by calling the API for the chosen seeds/count; do not copy expected accuracy values from a test or claim the ranker wins unless the measured result shows that.
There is no command-line runner or dashboard action for `RootCauseEvaluation`
yet; the test command validates the API but does not produce a user-facing
report. The security track has its own command-line runner,
`EvaluationRunner`, which writes a Markdown report (see `docs/evaluation.md`).

## 5. State the limitations

Explain that all cascade data is synthetic, the generated cascade structure determines what the ranker can learn, the live app has no historical-incident provider to train its Spring ranker, and the dashboard shows no root-cause evaluation report yet.
